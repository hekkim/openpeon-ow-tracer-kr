# tracer_kr — 트레이서 (Overwatch, 한국어)

오버워치 트레이서의 한국어 음성을 [CESP v1.0](https://openpeon.com) 이벤트 카테고리에 맞춰 묶은 사운드 팩입니다. "안녕, 친구들! 해결사가 왔어!"로 세션을 시작합니다.

## 설치

```bash
peon packs install tracer_kr
peon packs use tracer_kr
```
